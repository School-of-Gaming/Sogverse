# docs/investigations

Open explorations: a feature, gap, or question that was researched but not committed to.
A doc here exists so a later session can pick the question up without re-running the
research.

- **Nothing here is decided.** Every doc opens with a bold status line saying so, plus
  the date of the research — claims about external platforms and about our own code age
  at different speeds, and the reader has to know what to re-verify.
- **Record the journey, not just a conclusion**: what was checked, what was found, which
  way we lean, and what would change the answer.
- **An investigation ends one of three ways, and then leaves this directory:**
  - **Committed** → it becomes a `docs/plans/` plan (or a `TODO.md` item, with the
    owner's approval) and this file is deleted.
  - **Closed with a lesson** → distilled into `../records/` — good research that found
    no answer earns a record so it isn't re-run.
  - **Closed with nothing to keep** → deleted; git history suffices.
- A file sitting here means the question is still open. Never mark one "done".
