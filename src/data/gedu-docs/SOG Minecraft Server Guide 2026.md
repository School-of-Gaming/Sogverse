# 📜 Server Overview

# Server Overview

The School of Gaming Minecraft server is built around **the Hub**. The Hub acts as a central lobby, allowing players to travel to different parts of Sogverse. The Hub itself is also an adventure, as exploring it reveals the history of Sogverse and various hidden secrets.

Currently, anyone can join the SOG Minecraft server, but some areas are restricted to specific club groups or are only available during events.

The server includes various roles with different permissions. A player’s role is displayed in front of their name and in the player list accessed with the tab key.

The Hub and its open game modes are currently available 24/7. Server activity is monitored using tools such as a chat filter and game chat logs, which are visible to Server Staff.

School of Gaming clubs and camps are run on two separate server environments: **the Finnish server and the international server.**

# Moderation Commands

## Ban

Banning prevents a player from joining the server for the duration of the ban. The ban targets the player's hidden UUID, meaning they cannot bypass the ban by changing their character's name or IP address. The ban applies to the entire server, so a ban issued in the Hub will also affect the player in other areas like Open Survival.

| ❗ | *When a player’s actions on the server are restricted, a reason must always be provided. The reason should be noted briefly and clearly in the command.* |
| :---- | :---- |

| 👉 | /ban target lentgh reason /ban PlayerName 6 mo Inappropriate messages in chat./ban PlayerName 6 mo Breaking server rules \- theft. If the duration is left empty when banning a player, the ban will be indefinite (permanent). |
| :---- | :---- |
|  | **/unban PlayerName** Removes the ban. |
|  | **/banlist** Lists banned players. |

## Mute

Players can be muted for different durations. Muting is typically used during clubs or events when an issue can be addressed immediately, and removing the player from the server is not necessary. A muted player **cannot use the /msg or /whisper commands**, which prevents them from communicating in the game, even with a game educator.

| 👉 | /mute  /mute PlayerName 10m This command mutes the player for 10 minutes. The duration can be adjusted depending on the situation. |
| :---- | :---- |
|  | **/unmute**  /unmute PlayerName This command removes the mute from the player. |

## Kick

Kicking a player removes them from the server, but they **can rejoin** if they choose. This command is mainly useful in situations where **a non-member accidentally joins a server** during a lesson and does not leave when asked by the game educator.

Sometimes, extra players might end up in the wrong place, but they usually understand when you explain that the server is currently open only for those involved in the lesson.

| 👉 | /kick PlayerName |
| :---- | :---- |

# ⏸️ Club Break Tool

# Club Break Tool {#club-break-tool}

During the middle of a club session, a break is held. During the break, **all players are set to Adventure Mode**. Gedu controls the break using commands.

On-screen messages are shown in the player’s language: if the player’s Minecraft client is set to Finnish, the messages appear in Finnish. Otherwise, they appear in English. The messages also use different colors to indicate the current stage of the break.

## 5 minutes before the break

/gedu break soon  
This command notifies players that the break will start soon. It gives them time to prepare for the pause. The message disappears within a few seconds.

## Start break

/gedu break start  
This command starts the break and sets all players (except Gedu) to Adventure Mode.  
Note: Players may try to bypass the break by leaving and rejoining the server to regain Survival Mode.  
A message is shown on the screen indicating that the break is active. The message stays until the break is over.

## End break

/gedu break end  
This command ends the break, returning all players to Survival Mode. A message is displayed informing players that the break has finished.

# Handling rule violations privately  {#handling-rule-violations-privately}

We do not disclose the identity of the player who committed the theft or rule violation to other players, as this may lead to a cycle of retaliation. Instead, inform the affected player that the responsible player has been identified and that a game educator will handle the matter with them.

**If a player requires the stolen items immediately**, or if it is unclear whether the items can be returned, a moderator or game educator may facilitate the return of the items.

The player who committed the theft must return the items to a game educator, who will then handle their disposal. **The player is not allowed to keep any stolen items.**

# Automated moderation systems {#automated-moderation-systems}

## Chat Filters

The server uses a chat filter to prevent spam and the use of offensive language and profanity. Messages that trigger the filter are visible to game educators for review, but they are not sent to other players. From the player’s perspective, it appears that the message did not go through, and it will not be visible to anyone else in the server.

# General rules for building {#general-rules-for-building}

These general building rules take all players on the server into account. Since multiple groups may play on the same server on different days, it is important to follow shared building practices. Players (especially younger ones) may not always recognize where it is appropriate to build, so the game educator should guide them toward good building habits.

**Name your builds**  
All houses and other constructions should be named. This helps us identify ownership and makes it clear who to contact if a build is abandoned or needs review.

It also helps other players know who to ask for permission to visit or interact with a build.

**Don’t build too close to others**  
Always leave enough space between your build and your neighbor’s. This ensures that everyone has room to expand their construction if needed.

An exception applies if players have explicitly agreed to build close together.

**No building in shared server areas**  
Shared areas include roads, paths, and other public infrastructure or community structures.

No single player may claim part of a shared area for personal use. For this reason, building in public zones is not allowed. For example, players may not add personal balconies to pre-built apartment buildings on the server, since it becomes unclear what belongs to whom. The fairest solution is that no one builds in these areas.

**Unnecessary single pillars will be removed**  
Players often place single, isolated blocks (“pillars”) without purpose. If a pillar has no function, server staff may remove it.

These structures can disturb other players, as they often dominate the landscape visually.

# Mods and Shaders {#mods-and-shaders}

Minecraft allows a wide variety of mods and shader packs that can change the visual appearance of the game or add new features. However, for the sake of fair play, **it is important that no modifications are used that give players an advantage over others.**

This means that any mods or tools that provide extra gameplay information are not allowed. For example, X-ray mods, automated resource-finding tools, or minimaps that reveal caves, dungeons, or resource locations are strictly prohibited.

Visual-only shader packs and texture packs are allowed as long as they do not affect gameplay or provide additional information about the world. The goal is to ensure that all players have equal conditions and that the game remains fair and enjoyable for everyone.

**Allowed**

* Shader packs that improve lighting, shadows, or water reflections  
* Texture packs that only change the visual style of blocks or items  
* Performance mods (e.g. FPS optimizers) that do not affect gameplay or reveal information  
* UI or cosmetic mods that do not give gameplay advantages  
    
  **Not allowed**  
* X-ray mods or resource revealers  
* Minimaps that show caves, ores, dungeons, or other hidden structures  
* Automated mining or resource-finding tools  
* Any mod that reveals hidden player or world information  
* Any modification that provides a competitive advantage over other players

# 🧑‍🚀 NPCs

# NPCs {#npcs}

In Sofverse there are many NPCs with various tasks. While game educators cannot create NPCs, it is **important to know how to interact with them.**

NPCs can be player characters, animals, or objects. They may either remain stationary or move around, and players are not able to modify or break them.

**NPCs talk**  
Many NPCs will speak when a player approaches them. The chat is visible only to the player who triggered the interaction. This means that an NPC can display different lines to multiple players at the same time, but each player will only see their own conversation.

| 💡 | Some NPCs only speak when clicked, or the speech may appear as a speech bubble above the character’s head instead of in the chat. |
| :---- | :---- |
|  | Players can **trigger various actions** by interacting with an NPC. For example, in the Hub, an NPC can teleport a player to a predetermined location when the player clicks on the character. |

## Shopkeeper NPCs

Some NPCs have the ability to sell items. To open an NPC’s shop, **right-click on the character**. A menu will appear showing what the NPC offers and what is required in exchange for the items.

Laamalaakso on yksi School of Gamingin vanhimmista Minecraft-maailmoista. Se on perustettu **vuonna 2021** ja perustamispaikkaa merkkaakin valtava kirsikkapuu, joka näkyy kauas. Laamalaaksossa pelataan rentoa survivalia kaupunki-/maalaisteemaisessa ympäristössä. Pelaajat asuvat omissa kylissään, jonne he liikkuvat spawnina toimivan bussiaseman kautta. 

Laamalaakson sydän on kaupunkikeskusta Laamanmutka, jossa toimii myös suosittu Marketan Marketti. Kukkulan Auto \-nimisestä liikkeestä voi ostaa itselleen vaikka auton tai helikopterin ja Riimulan Hevosopistolla voi järjestää suuretkin ratsastuskilpailut.

Laamalaakso sopii pelaajalle, joka tykkää pelata survivalissa, mutta samalla myös tehdä rakennusprojekteja ilman, että zombiet ja creeperit väijyvät joka nurkalla. Vaikka Laamis on myös aloittelijaystävällinen, pääsee sielläkin vauhtiin ja vaarallisiin tilanteisiin kaivoksissa ja PVP-areenalla.

**Special features**  
🚗 Vehicles: Gamers can purchase and drive different types of vehicles.  
🪙 Coins: Gamers can earn coins by completing tasks.  
🛗 Elevators: Some buildings have elevators, so stairs are not needed.  
🛍️ NPC shops: Gamers can buy items from specific NPCs.

# Kerholaisten asuminen ja kylien ylläpito

Laamalaaksossa jokaisella ryhmällä on **oma kylä**, joka toimii ryhmän tukikohtana. Kerholaiset saavat kuitenkin asua ihan missä haluavat. Jokaisessa kylässä on kaksi bussia: toinen vie spawnille, toinen Laamanmutkan keskustaan Marketan Marketin eteen.

**Kerholaisten on laitettava oman kotinsa oheen kyltti, jossa lukee kuka talossa asuu. Suotavaa on myös laittaa postilaatikko, johon ohjaaja ja muut kerholaiset voivat tuoda kivoja ylläreitä.**

## Valmistalot

Kylissä on valmistaloja, johon uusi gamer voi muuttaa. Valmistaloa saa muokata kun sen on ottanut itselleen nimeämällä talon. Valmistaloja voi pyytää lisää tiketillä.  

## Kylän ylläpito

Kerhoissa on kaksi kertaa vuodessa suursiivous: kevätsiivous ja syyssiivous. Silloin puretaan pienemmät turhat rakennelmat ja merkataan purkuun isommat rakennelmat jotta serverin ylläpito voi ne purkaa. On kuitenkin hyvä pitää yllä palvelimen siisteyttä pitkin vuotta ja tarvittaessa **tiketöidä isommat turhat rakennelmat purkua varten**. Näin uusille ryhmäläisille tulee tilaa eikä serveri täyty autiotaloista ja keskeneräisistä projekteista.

Myös naapuriin on hyvä pitää välimatkaa, niin jokaisella on tilaa jatkaa oman kodin takapihaa tarvittaessa. Palvelimella riittää kyllä tilaa\! |

## Server Description

Lumolymy on Sogversen taikuuden keskus. Siellä sijaitsee myös taikakoulu Spelheim, jonka juuret todennäköisesi juontavat ikiaikaiseen loitsukiltaan. Lumolymyn upea maasto on houkutellut asukkaat eri puolille kolkkaa, mutta keskiössä on taikakylä Puzzlington. Puzzlingtonissa asuu muun muassa antitoksidanttien komendantti **Thora Kultakuuppa** ja taikakoulun rehtori **Raija Pihlaja**.

Spelheimin kirjastossa on ehkä enemmän salaisuuksia kuin kirjoja, mutta se on loistava paikka myös piiloleikkeihin.

Lumolymy sopii pelaajalle joka rakastaa seikkailuita eikä ole moksiskaan siitä, maailmassa tulee yö ja lohikäärmeet lepattavat ikkunan ohitse. Lohikäärmeet ovat muuten kilttejä, kunhan niille ollaan kilttejä.

**Special features**  
🪄 Magic: Gamers can use magic items and fly around with a broom.  
🐉 Mobs: Lumolymy has several special mobs, such as dragons flying around.  
🪙 Coins: Gamers can earn coins by completing tasks and buy items from each other or NPCs.  
🛍️ NPC shops: Gamers can buy items from specific NPCs.

Kun pelaaja oppii uusia taikoja, menevät ne Spell Inventoryyn. Spell Inventoryyn pääsee käsiksi kun sauvan pudottaa kädestä \[Q\].

Taiat saa käyttöön siirtämällä ne hotbarille kun Spell Inventory on auki. Inventoryn välilehtiä voi selata klikkaamalla inventoryn ulkopuolelle kun inventory on auki.

## Enchanting Table and Magic Items

Kun lumouspöytää klikkaa samalla kun pitää taikaeseinettä kädessä, voi esinettä muokata tai opetella uusia taikoja.Taikaesineen muokkaaminen maksaa Spell Pointseja.

* Opettele uusia taikoja  
* Muokkaa taikaesineen ulkonäköä  
* Muokkaa taikaesineen ominaisuuksia  
* Muokata sauvan controlseja (Cycle Mode, Inventory Mode, Chest Mode)

## Spawn  magical Mobs

/mmob spawn

Magic-plugari tuo Lumolymyyn myös kaikenlaisia erikoismobeja, joita pelikasvattajakin voi spawnata. Muista kuitenkin immersio ja käytä oikeuttasi spawnata mobeja tarinallisesti.

**❌ Ei**  
Gamer pyytää sinua spawnaamaan lohikäärmeen ja teet työtä käskettyä.

**✅ Vaan**  
Voit kertoa, että olet nähnyt esimerkiksi Puzzlingtonissa lohikäärmeitä juuri hetki sitten ja pyytää gameria matkustamaan sinne. Voit sitten vaivihkaa luoda Puzzlingtoniin lohikäärmeitä gamerin taistelutovereiksi.  
 

## Spell Points

Players collect Spell Points by casting spells at targets.

A game educator can give a player spell points with a command if necessary. Only give spell points when there is a valid reason. For example, if spell points were not awarded in the game due to an error, or if they are being used as a reward.

Spell points are part of the game mechanics, **and they are most meaningful when players earn them themselves.** This also helps keep the magic system as fair as possible for all players.
