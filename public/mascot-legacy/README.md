# Legacy School of Gaming characters — throwaway assets

These 34 PNGs are the **old** School of Gaming character set (the one-eyed
"Minion" and the Finnish pun cast), downscaled from the originals so the
mascot exploration page at `/mascot` can show each of them next to the thing
that replaces it.

They exist only for that comparison. **They are throwaway branch assets and get
deleted with the rest of the exploration** — the same cull that removes the
`/mascot` route, its proxy entry, the losing concepts and the `-legacy`
comparison modules. Nothing in the product links to this folder, and nothing
should start to.

Processing (from the supplied originals): transparent margins trimmed, longest
side resized to 256px with no enlargement, re-encoded as palette PNG at
compression level 9. 333 KB for all 34. Transparency is preserved; the art was
drawn for a white ground, which is why the page puts each of them on a light
tile.
